## Решение совместимости
Пользователь 18.10.2026 выбрал блокировку неоднозначных старых паролей.
Новые записи: `$qa-sha256-bcrypt-v1$` + bcrypt(base64(SHA-256(UTF-8 password))),
случайная соль и DefaultCost текущего bcrypt. Размер помещается в VARCHAR(255).
Старые bcrypt проверяются только для входа <72 байт. При >=72 всегда отказ 401:
даже ровно 72 байта неотличимы от усечённого длинного пароля. Старые короткие
пароли сохраняют доступ. Автомиграции после неоднозначного входа нет. Данные,
схема и аккаунты не удаляются. Восстановление доступа — отдельная согласованная
функция; сейчас её нет. Откат на старый бинарник не умеет читать новые хеши,
поэтому после новых регистраций откат требует поддержки версии, не сброса данных.

## Измерения
Go product: все production-пакеты, включая main; storetest — инфраструктура.
Vue: src TS/JS/Vue, включая bootstrap/router; .d.ts не исполняются.
Java: инфраструктура, включая page objects/API/fixtures/listeners; не продукт Go/Vue.
Неизмеренные shell/build scripts перечисляются отдельно, не исчезают из состава.

## Ограничения
Нет разрешённого Sonar сервера и отдельного бюджета model runtime.
Детерминированный тест evaluator не засчитывается как поведение LLM.
Дополнительные продуктовые требования нельзя вывести из реализации; до
согласования полнота всего продукта неизвестна.

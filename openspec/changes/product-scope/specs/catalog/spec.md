# Spec Delta

## Purpose

Публичный каталог элементов на главной странице: чтение данных через
`GET /api/items` и отображение состояний загрузки, результата, пустого списка
и ошибки. Изменение элементов в этой дельте не описывается.

## ADDED Requirements

### Requirement: CAT-001 Чтение элементов каталога
Главная страница SHALL при загрузке запрашивать `GET /api/items` и отображать
каждый элемент списка отдельной панелью с именем и описанием из ответа.

#### Scenario: CAT-001a Загруженный список
- **WHEN** API возвращает непустой список элементов
- **THEN** каждый элемент отображается со своим именем и описанием

### Requirement: CAT-002 Состояние загрузки списка
До получения ответа API область списка SHALL показывать состояние загрузки;
область списка имеет `aria-live="polite"`.

#### Scenario: CAT-002a Загрузка до ответа
- **GIVEN** ответ `/api/items` ещё не получен
- **THEN** область списка отображает текст загрузки на выбранном языке

### Requirement: CAT-003 Пустой каталог
При пустом списке или отсутствии поля `items` в ответе главная страница SHALL
отображать сообщение пустого каталога на выбранном языке.

#### Scenario: CAT-003a Пустой массив
- **WHEN** API возвращает `items: []`
- **THEN** отображается сообщение пустого каталога

#### Scenario: CAT-003b Отсутствие поля
- **WHEN** в ответе отсутствует поле `items`
- **THEN** отображается то же сообщение пустого каталога

### Requirement: CAT-004 Ошибка загрузки каталога
При ошибке запроса элементов главная страница SHALL отображать читаемое
сообщение об ошибке с текстом причины; страница остаётся доступной для чтения.

#### Scenario: CAT-004a Отказ API элементов
- **WHEN** `GET /api/items` завершается ошибкой
- **THEN** область списка показывает сообщение ошибки с текстом причины

### Requirement: CAT-005 Локализация хрома каталога
Заголовок панели и тексты состояний списка SHALL следовать выбранному языку
интерфейса; имена и описания элементов из API не переводятся.

#### Scenario: CAT-005a Русский интерфейс
- **WHEN** интерфейс переключён на русский
- **THEN** состояния списка отображаются по-русски, а данные элементов — как в API

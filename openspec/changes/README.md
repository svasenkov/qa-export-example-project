# Изменения

Создавайте отдельный каталог для согласованной задачи через локальный CLI
из [tools/openspec](../../tools/openspec/README.md). Порядок работы —
в [основном README](../README.md).

Не создавайте change из иллюстративного примера без задания на его реализацию.
В частности, клиентская проверка максимальной длины логина пока не добавлена:
текущее поведение зафиксировано в FORM-002.

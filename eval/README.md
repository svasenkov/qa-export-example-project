# Оценка работы агентов

Каталог зарезервирован для будущих eval агентов из [agents/](../agents/README.md).
Здесь пока нет заданий, датасетов, runner, результатов или подключения к моделям.
Наличие каталога не означает, что качество агента измерено.

Продуктовые тесты остаются в модулях из [профиля](../docs/coverage-profile.md).
Eval сможет использовать их как часть проверки результата агента, но успешный
прогон продукта сам по себе не доказывает качество всего агентского процесса.

При первом eval определите:

- задание, исходное состояние проекта и доступные агенту материалы;
- версию агента, skills, спецификаций и конфигурацию запуска;
- критерии результата, способ измерения и допустимые действия;
- независимые проверки результата, ограничения среды и учёт пропусков;
- отдельные артефакты каждой попытки, без перезаписи предыдущих результатов.

Задания, критерии и результаты должны храниться раздельно. Если задание требует
скрытых эталонов или независимого оценивания, не включайте их в доступный агенту
контекст. Самооценка агента не заменяет независимую проверку или проверку человеком.

Для связи с продуктом используйте пути capability и стабильные ID требований/
сценариев из [OpenSpec](../openspec/README.md), а не копии требований в датасете.
Для воспроизводимости сохраняйте также ревизию или хеш содержимого спецификации:
один ID может переживать изменения поведения. Способ хранения и формат runner
выберите вместе с первой реальной задачей; пустые универсальные схемы сейчас не нужны.

Работа с платными моделями, внешними стендами и публикацией результатов задаётся
отдельным объёмом задания. Эта заготовка ничего не запускает и не выдаёт таких разрешений.

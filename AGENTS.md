# Работа с проектом

Отвечай по-русски.

Перед работой прочитай [профиль проекта](docs/coverage-profile.md):
он определяет модули, выбранные стеки и доступ к ним.
Команды бери из README соответствующего модуля.
Требования — из задания и относящихся к нему [контрактов](_contract/README.md).

## Выбор процедуры

Открой подходящий SKILL.md и указанные в нём материалы:

- [Запуск тестов](skills/qa-run-tests/SKILL.md).
- [Диагностика падения](skills/qa-debug-test/SKILL.md).
- [Добавление теста](skills/qa-write-test/SKILL.md).
- [Аудит покрытия](skills/qa-coverage-audit/SKILL.md).

Для остальных задач используй README затрагиваемого модуля.
Справочные материалы — в [базе знаний QA](docs/qa/README.md).

## Ограничения

Сохраняй пользовательские изменения и прежние результаты проверок.
Commit, push, публикация и действия на внешних стендах требуют
разрешения в текущем задании; уже данное разрешение повторно не запрашивай.
Не включай секреты в код, логи и отчёты.

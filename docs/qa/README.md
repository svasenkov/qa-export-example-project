# База знаний QA

Здесь хранятся объяснения и принципы, которые нужны человеку и агенту при работе над проектом. Skills описывают порядок действий; база знаний объясняет решения. Конкретные команды и соглашения выбранного стека находятся в README модуля и документах, на которые он ссылается.

- [Проверки и покрытие](testing.md): выбор уровня, требования, результаты выполнения и смысл «100%».
- [HTTP CRUD](crud-http.md): коллекции и одиночные ресурсы, PUT/POST/PATCH/DELETE, JSON Merge Patch, ошибки и проверки прав доступа.
- [Page Object и fluent](page-objects.md): ответственность страниц и компонентов, цепочки вызовов, локаторы и ожидания.
- [Тестовые данные и API-клиенты](test-data.md): подготовка, изоляция, очистка и отрицательные проверки.
- [Результаты и диагностика](test-results.md): доказательства, шаги отчёта, секреты и повторные запуски.
- [Проверка harness](harness-checks.md): структура файлов и отдельная проверка поведения агента.

Начинай с темы задачи. Для деталей реализации переходи в документацию модуля из [профиля](../coverage-profile.md). Не переноси соглашения Java, Selenide или Allure в другой стек автоматически.

# Определения агентов

Каталог зарезервирован для будущих агентов проекта. Сейчас запускаемых агентов,
оркестратора и интеграций с провайдерами здесь нет.

Разделение ответственности:

- [AGENTS.md](../AGENTS.md) — общая инструкция работы в репозитории.
- [skills/](../skills) — процедуры запуска, диагностики, написания и аудита тестов.
- `agents/` — будущие роли: назначение, входы и выходы, используемые skills,
  доступные инструменты, ограничения и способ запуска.
- [eval/](../eval/README.md) — отдельная оценка работы этих агентов.
- [openspec/](../openspec/README.md) — требования к наблюдаемому поведению продукта
  и, по мере появления, к возможностям агентов.

Для первого агента сначала определите задачу и критерии результата, затем выберите
runtime и его формат конфигурации. Не вводите универсальный формат заранее.
Каждому агенту понадобится стабильный идентификатор и воспроизводимая версия
инструкций, чтобы результаты eval можно было связать с конкретным запуском.

`agents/` не равен служебному `.agents/`: runtime может использовать `.agents/skills/`
для обнаружения skills, но наличие файлов в этом каталоге не активирует агента.
Адаптеры runtime должны ссылаться на общие процедуры, а не создавать расходящиеся копии.
При добавлении проверяемой возможности создавайте OpenSpec capability по её поведению;
не создавайте пустую спецификацию только потому, что существует этот каталог.
